# Comprobación final

- [ ] Una persona nueva reconstruye desde una base vacía con los pasos escritos.
- [ ] Versión y herramientas están identificadas en Ubuntu, Windows y macOS.
- [ ] Las diez reglas tienen implementación o un límite declarado.
- [ ] Claves candidatas y dependencias justifican la normalización.
- [ ] Datos incluyen ausencias válidas, fronteras y relaciones múltiples.
- [ ] Ocho consultas responden preguntas precisas y explican cada fila.
- [ ] Se conserva precio o estado histórico cuando el dominio lo necesita.
- [ ] Restricciones aceptan casos válidos y rechazan inválidos.
- [ ] Operación transaccional verifica filas y revierte un fallo.
- [ ] Dos conexiones no violan la regla compartida.
- [ ] Permisos se prueban con roles distintos del propietario.
- [ ] Importación conserva raw y reconcilia aceptadas/rechazadas.
- [ ] Planes tienen volumen y estadísticas; conclusión usa evidencia.
- [ ] Backup se restaura en otra base y se comparan objetos y valores.
- [ ] Política de permisos tras restaurar está declarada y probada.
- [ ] No hay credenciales, datos reales privados ni instrucciones ajenas al estudiante.
