# Unidad 32 — Proyecto final

- problema/alcance;
- DER;
- esquema;
- PK/FK/restricciones;
- datos de prueba;
- consultas;
- joins/agregaciones;
- vista;
- transacción;
- índices justificados;
- EXPLAIN;
- roles;
- backup/restauración;
- README reproducible.
